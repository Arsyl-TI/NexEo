# NexEo Autonomous Feature Ideas

1. **Global Quick Search Command Palette modal (`Ctrl+K` or `Cmd+K`)**
   - Universal search modal accessible from any page to quickly jump to any video, novel, chapter, or shared file across NexEo.

2. **Novel Offline EPUB & TXT Exporter / Downloader**
   - Adds an "Export/Unduh Novel (EPUB/TXT)" button on the novel detail page so users can download entire novels as formatted EPUB files for offline E-Readers or tablets.
